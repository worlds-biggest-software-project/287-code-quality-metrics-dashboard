# Code Quality Metrics Dashboard — Feature & Functionality Survey

> Candidate #287 · Researched: 2026-05-03

## Core Features

Primary solutions: SonarQube, Code Climate, CodeFactor, Codacy, Better Code Hub.

**Must-have**: Code complexity calculation, duplication detection, test coverage measurement, code smell detection, security vulnerability scanning, trend tracking, dashboard visualization.

**Differentiating**: Machine learning anomaly detection, automatic issue triage, architectural pattern analysis, dependency risk assessment, technical debt estimation.

**Underserved**: Cross-repository benchmarking, developer-friendly actionable recommendations, integration with development workflow, continuous improvement tracking.

**AI-augmentation**: Intelligent issue classification, automatic fix suggestion, developer education recommendations.
